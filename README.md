# UMART Landing Page

## Organización del proyecto

- `html/`: páginas activas del sitio: `landingPage.html` (principal), `galeria.html` e `historias.html`.
- `css/`: hoja de estilos compartida por las páginas.
- `cpp/`: archivos con extensión `.cpp`.
- `assets/`: logotipo e imágenes utilizadas por las páginas.

El `index.html` de la raíz funciona como acceso directo a `html/landingPage.html` y conserva la entrada habitual para GitHub Pages. Todas las páginas y sus recursos usan rutas relativas para mantenerse conectados desde esta estructura.
